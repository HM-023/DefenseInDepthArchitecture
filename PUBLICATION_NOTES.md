# Publication decisions

The historical shared EVE-NG layout and its derived inventory are excluded because publication permission has not been established. The included 11-node reference layout was newly authored as a generic example with fictional node names and isolated bridge networks. It is not a redaction or replica of the historical lab.

Original reports, screenshots, branding, identities, configuration exports and appliance firmware remain private. The reference layout has passed static XML/link checks; EVE-NG import, device boot and policy enforcement have not been tested. No blanket license is applied to historical shared work.
